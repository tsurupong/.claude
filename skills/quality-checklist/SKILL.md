# 完了前チェック

## 共通
- [ ] 依頼の全項目に対応した/やらなかった事を明記した
- [ ] 結論が先頭にある。受け手が次に取る行動が明確
- [ ] 全ての主張に根拠(パス・行・実測値・出典)が付く
- [ ] 自分で検証した(動かした/読み返した/再計算した)。検証方法を書いた

## コード
- [ ] テスト実行済みで結果を貼った(「通るはず」禁止)
- [ ] 変更は依頼の直線上のみ(ついで変更なし)
- [ ] 秘密情報のハードコードなし
- [ ] 既存のスタイル・命名に合わせた

## 文書・教材
- [ ] 対象読者の前提知識で読める
- [ ] 手順は全部自分で実行してから書いた
- [ ] 例が動く(コピペで再現可能)

## 診断・調査
- [ ] 重要結論は独立した2手段で裏取りした(別ツール/別データソース/別実行経路。
      同一手段の繰り返しは1手段と数える)
- [ ] 確度の低い箇所に「未確認」と明記
- [ ] 環境を変更していない(read-only約束時)
