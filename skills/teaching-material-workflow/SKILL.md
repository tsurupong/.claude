# 教材制作フロー

1. **前提知識の明文化**: 対象者が知っていること/知らないことを冒頭に書く。
2. **つまずき予測**: 環境差(OS/バージョン)・タイポしやすい箇所・概念の飛躍点を列挙し、
   各所に注意書きを先回りで置く。
3. **最初の10分に成功体験**: 最小の「動いた!」を教材の最初に配置する。
4. **段階演習**: 完成形を見せる → 穴埋め → 白紙から、の3段階で同じ題材を繰り返す。
5. **実行検証**: 全手順をクリーンな環境相当で自分で実行してから書く。
   実行していない手順は教材に載せない。
6. **バージョン管理**: 使用ツールのバージョンを教材に明記。四半期ごとに動作再確認。
7. **完了条件**: quality-checklist 通過+「配布物だけで再現できるか」の自己テスト。
