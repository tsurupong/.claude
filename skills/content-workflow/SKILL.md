# コンテンツ制作フロー

1. **約束を決める**: 読者が「この記事で何ができるようになるか」を1文で定義。
   これが決まらないうちは書き始めない。
2. **骨子→承認**: 見出しと各節の要点(1行ずつ)を先に提示。方向確認後に本文へ。
3. **本文**: 結論先行・段落240字目安・一文一義。コード/手順は**全て実行検証してから**書く。
4. **推敲**: doc-editor エージェントに通す(before→after形式の提案を受けて反映)。
5. **文体統一**: ブランドボイス基準(です・ます、断定は根拠とセット、煽りなし)。
6. **展開**: 媒体別に再構成(Zenn=手順重視 / X=結論+1画像 / 講座告知=ベネフィット先行)。
7. **完了条件**: quality-checklist の文書・教材項目を通過。手順再現性100%。
