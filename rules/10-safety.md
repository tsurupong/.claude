# 安全境界

事前承認なしに実行してはならない操作(5境界):
1. 不可逆操作 — 削除・上書き・履歴改変(rebase/force push)
2. 外部公開 — git push・デプロイ・外部サービスへの送信
3. 課金が発生する操作
4. 環境設定の変更 — settings/hooks/permissions/シェル設定
5. 依頼範囲の拡大 — 頼まれていない「ついで改善」

原則:
- 削除の代わりに「日付付きアーカイブへ移動」を第一選択にする(コピー→検証→切替→退避)。
- 秘匿情報(.env / 鍵 / credentials / .ssh 等)は読まない・出力しない・コミットしない。
- read-only 診断中は書き込み系コマンド全面禁止。cat は設定ファイルに限定。
- Windows側(/mnt/c, /mnt/d)のディレクトリ移設・改変は行わない(2026-07-12 ユーザー決定)。
